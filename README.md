Este proyecto implementa un sistema básico para el control de datos de profesores del departamento de Informática, utilizando una Lista Simplemente Enlazada como estructura de datos principal.

De cada profesor se almacena la siguiente información:

Nombre

Edad

Categoría docente (Instructor, Asistente, Auxiliar, Titular)

Funcionalidades implementadas
a) ProxCambio()
Devuelve un listado con los nombres de los profesores Instructores con más de 26 años, que son los próximos a realizar cambio de categoría para Asistente.

b) MostrarLista()
Devuelve un listado con la información completa de todos los profesores, ordenados por edad de mayor a menor.

c) CantProfesores()
Devuelve en un String la cantidad de profesores por cada categoría docente (Instructores, Asistentes, Auxiliares y Titulares).
